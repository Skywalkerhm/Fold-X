CASE 02 / 快速准确的行动决策

超级玛丽：在变化中及时行动

面对移动的敌人、变化的地形与有限的行动时机，Fold-X 根据当前游戏状态持续选择前进、跳跃或等待。左侧看行动效果，右侧看当时的状态、所选动作与候选分数。

从策略选择进一步走向时机把握：环境持续变化，判断需要及时转化为有效动作。

应用价值 · 适用于游戏智能体、交互应用与需要连续反馈的行动选择。

观察结果与证据边界
  • 录屏包含多个关卡的连续行动，结束于 4-3 关卡。
  • 右侧面板是状态与决策摘要；候选分数不是实测准确率或通关概率。

速度口径 · 全段 5 倍速；真实请求耗时应按运行记录统计，不能从播放速度推算。

演示用于观察行动时机与效果，未统计多次运行成功率，不表示全游戏通关，也不据此声称仅靠原始像素控制。

CASE 03 / 复杂环境决策

机器人配送：把随机变化纳入连续决策

在 UE 城市仿真中，Fold-X 根据天气、行人、车辆、信号和任务进展持续作出判断，完成三单配送及返站。场景中的随机变化及其对能见度、通行条件和交互的影响，均纳入连续决策。

从及时选择一个动作，推进到在变化环境中持续完成任务：出发、途中判断、送达、返站，再开始下一单。

应用价值 · 探索园区配送、巡检和服务机器人中的连续任务决策：在环境变化与交互打断下，持续围绕目标调整行动。

观察结果与证据边界
  • 完整三单记录：三次送达、三次返站；日志未记录行人或车辆接触，记录一次静态路缘接触。
  • 路缘处理专项：单独完成一次送达及返站，记录一次主动跨阶，未记录接触事件；该结果仅限这次独立专项运行。
  • 随机场景机制及现场信息进入决策流程已核对；本次运行未记录随机起点触发，也尚无多随机种子的汇总成绩。

两段视频均为 5 倍速；完整录像约 20 分钟，展示约 4 分钟；专项录像约 2 分 24 秒，展示约 29 秒。播放时长不代表真实任务耗时或单次决策延迟。

本例为一次 UE 仿真运行，不代表实体机器人部署或多次随机试验的成功率。路线选择在预设候选范围内进行，不能描述为无约束自主探索。

CASE 04 / 多个决策点的协同

交通信号调度：持续协调 62 个路口

Fold-X 根据仿真中不断更新的车流，参与 62 个路口的信号决策。一个路口的放行会影响后续路段，局部选择需要放到整个路网中观察。

从一个行动主体推进到多个相互影响的节点：各路口既有局部需求，也共同影响路网运行。

这是动态仿真与回放，不代表真实城市部署、全局最优，也不证明单次 API 调用完成全部 62 个路口的判断。

CASE 07 / 审美理解与细节鉴察

CASE 08 / 精细视觉质检

精细视觉质检：发现疑似问题，定位细节并复核

面向床品清洁质检，在纹理、褶皱与低对比度画面中发现疑似发丝，标出位置并放大复核。重点展示发现疑似问题、定位证据、辅助人工复核的视觉质检能力。

从理解画面进一步走向质量检查：以细小异物检测为切入，判断哪些区域值得关注，并提供可复核的质检线索。

应用机会 · 把需要人工逐帧寻找的细节整理为候选位置，辅助复核与留档，为布草检查、纺织品异物筛查等场景提供试点方向。

观察结果与证据边界
  • 演示先将检测范围限定为床品，再扫描视频并呈现候选结果。
  • 结果列表显示两个时间点的候选，红框标出位置，可打开结果逐级放大查看。
  • 画面中的候选评分不是标注数据上的准确率；本例不证明对所有细小目标均能可靠识别。

本例是功能演示，尚未提供生产现场的漏检率、误检率或吞吐验证；不将放大显示等同于提高原始画面分辨率。

速度口径 · 演示短片约 46 秒，包含剪辑与放大展示，不作为端到端检测耗时或毫秒级延迟的证据。

常见问题

Fold-X 是什么？

一个多模态决策模型，面向文字与图像中的判断、选择和评分任务，目标是让决策更准、更快、更省。当前可通过 Flash-1.3 API 接入。

哪些任务适合先试？

分类、条件判断、候选选择、评分与图像条件筛选。先选有明确输入、输出和验收标准的任务，用代表性样本验证。

八个演示可以直接通过 API 运行吗？

API 提供判断能力；视频搜索、游戏、机器人和交通应用还需要取帧、环境连接、动作执行等配套集成。演示并不等于完整应用已作为标准服务交付。

中文支持体现在哪里？

覆盖中文词义、句间关系、多义表达和修辞判断。Flash 深度配置在 C-SEM 公开集四项共1,200题的团队自测中，宏平均为93.33%；不等于所有中文任务的准确率。

“准、快、省”是对所有任务的保证吗？

是产品追求，并非无条件保证。准确性看具体任务；速度区分模型耗时与端到端API耗时；费用按完整任务计算。案例与评测页逐项说明测试条件和边界。

返回的分数就是正确概率吗？

不是。分数用于比较候选或设置筛选阈值，不能直接视为真实正确率。上线前应在自己的业务数据上验证，必要时设置人工复核。

如何调用、计费和申请试用？

通过HTTPS文字或图像接口调用。当前支持计点和计时授权，价格与额度在开通时确认。联系两位创始人申请试用，普通产品问题也可在GitHub Issues留言。

会公开代码、权重或客户资料吗？

本仓库只展示产品能力、评测摘要和应用素材，不发布核心实现、模型权重、密钥或客户原始数据。企业资料与数据处理要求通过非公开渠道另行确认。
